# Adam Portfolio

A static personal portfolio for Adam, a student builder from Egypt working across software, data analysis, AI, and robotics.

## Stack

- Semantic HTML
- CSS
- Vanilla JavaScript

## Local preview

Open index.html in a browser, or serve this directory with a static web server.

## Checks

Run:

    npm run check

## Deployment

The included GitHub Actions workflow publishes the site to GitHub Pages whenever changes are pushed to the default branch. In the repository settings, set Pages source to GitHub Actions.

## Structure

- index.html — page structure and content
- styles.css — responsive visual system
- main.js — navigation, filters, and reveals
- .github/workflows/deploy-pages.yml — GitHub Pages deployment

Project claims are based on local source evidence. Training datasets used in the data-analysis work are synthetic or Kaggle-sourced practice data.
